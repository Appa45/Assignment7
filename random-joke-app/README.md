# Random Joke Generator

A responsive React + Vite application that fetches a random joke from the Official Joke API.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The app uses only this endpoint:

`https://official-joke-api.appspot.com/random_joke`

Create `submit.txt` in the project root and put only your deployed application URL in it before running the assessment script.
